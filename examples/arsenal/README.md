# Arsenal demo fixtures

Inert inputs for the Black Hat Asia 2027 Arsenal demonstration of `unk-scanner`. They contain no malware, no working infrastructure (`example.invalid` cannot resolve) and nothing that runs on load; the scanner only parses them.

| File | Shows | Expected |
| --- | --- | --- |
| `01-copy-button.js` | A documentation copy button | `clipboard-write` note only |
| `02-clickfix.js` | A copy handler that substitutes a built, detached download command | `clickfix-clipboard-command` error with the resolved command |
| `03-string-array.js` | An obfuscator.io-style RC4 string array with a checksum rotation loop | rotation 9 recovered by checksum; hidden URL and `require('child_process')` reported |
| `04-language-client.js` | A language client launching the editor binary as Node | `electron-run-as-node` warning |
| `05-hidden-launch.js` | The same variable set in generated PowerShell launched with a hidden window | `electron-run-as-node` error |

```sh
npm install --global unk-scanner --ignore-scripts
unk-scanner examples/arsenal/02-clickfix.js
unk-scanner --format sarif --fail-on error examples/arsenal/ > arsenal.sarif
```

`03-string-array.js` is generated by `test/fixtures/obfuscate.mjs`.
