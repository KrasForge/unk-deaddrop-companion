# Handling research input

Use held files in an isolated analysis environment. Do not install samples or
open suspect projects in an editor that can run workspace tasks. This tool reads
input bytes and parses syntax; parser vulnerabilities and resource exhaustion
remain possible. Its byte limit is a convenience, not a sandbox.

Report tool defects with synthetic reproductions. For a sensitive issue, use
GitHub private vulnerability reporting if enabled; otherwise withhold the
sensitive attachment until the maintainer supplies a private channel.

Do not upload original case files, payloads, victim lists, provider identifiers,
authentication tokens or unreviewed analysis output.
